# Codename Resolution Reference

Remove customer/project codenames from public instructions and docs.

- Replace codenames such as internal project labels with generic package names.
- Do not preserve initials, phonetic hints, product-category hints, account names, or domain names.
- If a private codename is needed for execution, it belongs only in a private registry or manifest.
- Public examples must use synthetic, obviously fake names and still pass leakage scans.

For this package, the generic public name is `amazon-ads-masked-optimization-output`.
