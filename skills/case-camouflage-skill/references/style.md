# Style Reference

Use direct operator language.

- Say "masked handle" rather than "anonymous customer".
- Keep tables action-oriented and exact.
- Put profile handles beside profile-scoped handles.
- Say "not executed" when no write occurred.
- State limitations without implying metrics were altered for privacy.
- Avoid decorative anonymization, story-like aliases, or playful product names.

Recommended row columns:

`action_id`, `profile`, `entity`, `action_type`, `current_value`, `proposed_value`, `exact_metrics`, `why`, `risk`, `approval_status`, `preflight`, `readback`, `monitoring`.
