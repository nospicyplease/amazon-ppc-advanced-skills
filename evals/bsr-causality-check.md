# BSR Causality Check

Use this review prompt when a skill discusses BSR, rank, organic sales, or PPC-to-organic effects.

```text
Review the skill output below for BSR and rank-causality discipline.

Check whether the output:
1. Treats BSR as a category-relative velocity signal, not a standalone cause.
2. Explains that lower BSR is better when direction could be confusing.
3. Avoids claiming ads caused BSR movement unless timing, total sales/orders, organic rank, control changes, and alternative explanations support it.
4. Flags missing competitor/category context as a confidence limiter when relevant.
5. Separates correlation, hypothesis, and high-confidence causal claims.
6. Avoids recommending rank-growth spend from BSR alone.

Return:
- Pass / Needs revision / Fail.
- Any unsupported causality claim.
- What evidence would be needed to make the claim stronger.
- A safer wording suggestion.
```
