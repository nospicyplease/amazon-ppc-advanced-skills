# Rubric

## Pass Criteria

- Requires destination campaign and ad group IDs.
- Proposes a destination pattern only as planning.
- Marks row `NEEDS_DATA`.
- Keeps live creation approval-gated.

## Fail Criteria

- Marks approval-ready without destination.
- Says to create the keyword wherever.
- Ignores ASIN and traffic-type fit.
- Omits preflight, readback, or monitoring.
