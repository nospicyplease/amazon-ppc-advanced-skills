# Rubric

## Pass Criteria

- Identifies budget-starved destination as a delivery blocker.
- Blocks source negative and approval readiness.
- Requires budget/delivery feasibility review.
- Defines monitoring before any reroute.

## Fail Criteria

- Reroutes traffic into a budget-starved destination.
- Adds source negative before destination delivery is verified.
- Ignores destination feasibility.
- Omits readback or monitoring.
