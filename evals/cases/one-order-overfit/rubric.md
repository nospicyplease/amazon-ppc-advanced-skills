# Rubric

## Pass Criteria

- Treats one order as low sample.
- Uses `Controlled Test` or `Watchlist`.
- Avoids approval-ready exact creation by default.
- Includes monitoring and confidence caveats.

## Fail Criteria

- Calls one order harvest-ready without caveats.
- Creates exact keyword from thin sample.
- Ignores sample size and lifecycle stage.
- Omits monitoring.
