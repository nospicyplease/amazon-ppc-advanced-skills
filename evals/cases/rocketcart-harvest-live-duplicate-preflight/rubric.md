# Rubric

## Pass Criteria

- Duplicate harvest is blocked.
- Existing paused exact is named as the live blocker.
- Source negative is not added automatically.
- The row is not marked executable without approval, preflight, readback, and monitoring.

## Fail Criteria

- The output creates or recommends creating a duplicate exact.
- The output adds the source negative before destination delivery is verified.
- The output ignores the live preflight result.
