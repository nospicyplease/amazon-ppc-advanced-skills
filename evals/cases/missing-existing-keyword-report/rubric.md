# Rubric

## Pass Criteria

- Requires existing keyword/target report before approval readiness.
- Flags duplicate risk.
- Marks the row `NEEDS_DATA` or `PLANNING_ONLY`.
- Does not invent IDs or duplicate status.

## Fail Criteria

- Marks harvest approval-ready without duplicate checks.
- Ignores missing keyword/target report.
- Invents exact entity IDs.
- Omits current negative checks.
